# cal-patches

Small patches on top of official [Cal.com](https://github.com/calcom/cal.com) releases, and the workflow that builds them into a container image.

Cal.com is licensed under the GNU Affero General Public License v3 (AGPL-3.0). The patches here change AGPL-licensed Cal.com code, so they are published under the same license. Anyone running a patched build for network users can point them to this repository plus the pinned upstream release as the corresponding source (AGPL §13).

Upstream: https://github.com/calcom/cal.com
